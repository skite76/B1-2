
# 아이스 라떼 10초 광고 제작 보고서

## 1. 미션 소개

이번 미션은 생성형 인공지능 도구를 활용하여 10초 이내의 브랜드 광고 영상을 제작하는 과제이다.  
나는 카페 음료 브랜드 **아이스 라떼**를 주제로 광고를 기획하고 제작하였다.

광고의 핵심은 **지친 하루에 아이스 라떼 한 모금이 기분을 바꿔 준다**는 메시지를 짧고 쉽게 전달하는 것이다.

스토리보드는 **지피티-이미지-2**로 제작하였다.  
처음에는 **소라-2**로 광고 영상을 만들었지만, 영상 속 인물이 스토리보드 속 인물과 많이 달랐다.  
그래서 소라-2 영상은 최종 결과물로 사용하지 않았다.

최종 광고 영상은 **나노바나나**를 사용하여 스토리보드 속 인물과 최대한 일치하도록 다시 제작하였다.

## 6. 제작 과정

1. 광고 브랜드를 **아이스 라떼**로 정했다.
2. 광고 콘셉트를 **“지친 하루를 깨우는 한 모금”**으로 정했다.
3. 10초 안에 전달되도록 장면을 5개로 나누었다.
4. 지피티-이미지-2로 스토리보드 이미지를 만들었다.
5. 소라-2로 광고 영상을 제작해 보았다.
6. 하지만 소라-2 영상 속 인물이 스토리보드 인물과 많이 달라서 사용하지 않았다.
7. 나노바나나를 사용해 스토리보드 인물과 일치하도록 영상을 다시 만들었다.
8. 최종적으로 나노바나나로 만든 광고 영상을 채택하였다.

## 7. 광고 대본

### 장면 1 — 피곤한 순간

학생 또는 직장인이 책상 앞에서 지친 표정으로 앉아 있다.  
화면은 어둡고 조용한 분위기이다.

### 장면 2 — 음료 등장

책상 위에 시원한 아이스 라떼가 놓인다.  
컵 표면에는 물방울이 있고, 얼음이 보인다.

### 장면 3 — 한 모금의 변화

주인공이 아이스 라떼를 마신다.  
마시는 순간 화면이 밝아지고 표정이 살아난다.

### 장면 4 — 기분 전환

주인공이 아이스 라떼를 들고 밝게 미소 짓는다.  
처음보다 훨씬 상쾌한 분위기가 된다.

### 장면 5 — 제품 강조

아이스 라떼 컵이 크게 보이고 마지막 문구가 나온다.

**오늘의 충전, 한 모금이면 충분해.**

## 11. 프롬프트 수정 전후 기록

### 수정한 장면(나노바나나)

장면 3 — 주인공이 아이스 라떼를 마시는 장면(나노바나나에서 따로 표정변화와 목소리 설정을 추가함)

### 문제 상황

처음에는 소라-2로 광고 영상을 제작했다.  
하지만 소라-2 영상 속 인물이 지피티-이미지-2로 만든 스토리보드 속 인물과 많이 달랐다.

광고에서는 같은 인물이 피곤한 상태에서 밝아지는 변화가 중요하다.  
그런데 인물이 달라 보이면 같은 사람의 변화처럼 느껴지지 않았다.  
그래서 소라-2 영상은 최종 결과물로 사용하지 않았다.

### 수정 전 입력 문장

지친 사람이 책상 앞에서 아이스 라떼를 마시고 기분이 좋아지는 광고 영상

### 수정 후 입력 문장

스토리보드 속 인물과 같은 젊은 직장인이 책상 앞에서 아이스 라떼를 마시는 장면, 같은 얼굴형과 비슷한 머리 모양 유지, 아이스 라떼를 마시는 순간 어두운 조명이 밝아지고 표정이 자연스럽게 좋아지는 광고 영상

### 수정 이유

수정 전 문장은 인물에 대한 설명이 부족했다.  
수정 후에는 인물의 얼굴형, 머리 모양, 표정 변화, 조명 변화를 구체적으로 넣었다.  
이후 나노바나나를 사용하여 스토리보드 인물과 더 비슷하게 맞춘 최종 영상을 제작하였다.

## 12. 제작 중 발생한 문제와 해결 방법

| 문제 | 원인 | 해결 방법 |
|---|---|---|
| 소라-2 영상 속 인물이 스토리보드 인물과 다름 | 이미지 생성 도구와 영상 생성 도구가 인물을 다르게 해석함 | 소라-2 영상은 사용하지 않고, 나노바나나로 최종 영상을 다시 제작 |
| 장면마다 분위기가 달라질 수 있음 | 장면을 나누어 생성했기 때문 | 모든 장면에 어두움에서 밝아지는 흐름을 반복해서 입력 |
| 10초 안에 메시지를 전달하기 어려움 | 장면과 문구가 많으면 복잡해짐 | 자막을 생략하고 핵심 장면만 사용 |

## 13. 소라-2 사용 결과와 한계

소라-2는 영상의 움직임을 만드는 데는 도움이 되었다.  
하지만 이번 광고에서는 주인공의 일관성이 중요했다.

소라-2로 만든 영상은 스토리보드 속 인물과 얼굴, 분위기, 느낌이 많이 달랐다.  
그래서 최종 광고 영상으로 사용하기에는 적합하지 않다고 판단했다.

이번 작업을 통해 영상 생성 도구를 사용할 때는 단순히 움직임이 자연스러운 것뿐만 아니라,  
스토리보드와 인물, 분위기, 메시지가 잘 맞는지도 중요하다는 것을 알게 되었다.

---

## 14. 최종 영상 선택 이유

최종 광고 영상은 나노바나나로 만든 영상을 선택하였다.

그 이유는 다음과 같다.

1. 스토리보드 속 인물과 가장 비슷하게 표현되었다.
2. 장면 사이의 인물 차이가 적었다.
3. 피곤함에서 상쾌함으로 바뀌는 흐름이 잘 보였다.
4. 광고의 핵심 메시지인 “오늘의 충전, 한 모금이면 충분해.”가 잘 전달되었다.

최종 영상은 지친 주인공이 아이스 라떼를 마신 뒤 밝아지는 흐름으로 구성하였다.  
마지막 9초에서 10초 구간에는 아이스 라떼 제품을 크게 보여 주고 브랜드명을 표시하여 광고 메시지를 강조하였다.
